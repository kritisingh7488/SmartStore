# SmartStore AI

SmartStore AI is a modern, premium e-commerce platform built on the MERN stack (MongoDB, Express, React, Node.js). 
It features a full Admin dashboard, AI-powered product descriptions, a global shopping cart, and a beautiful UI.

## Features
- **User Store:** Glassmorphic UI, dynamic cart, AI product descriptions.
- **Admin Dashboard:** Manage products, generate AI content, track sales analytics.
- **Authentication:** JWT-based secure login and registration.

## Getting Started
1. `cd backend && npm install && npm start`
2. `cd frontend && npm install && npm run dev`
